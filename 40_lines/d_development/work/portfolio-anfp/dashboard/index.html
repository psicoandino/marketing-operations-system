Prospect Lifecycle — Marketing Operations Dashboard

How does a prospect evolve through the operational system? This is the primary question this dashboard answers, before any aggregate marketing-operations question. This increment implements the Lifecycle Status view, the Acquisition → Enrollment Trend view, and the Origin view; the remaining required view (Program Interest) is scaffolded below and arrives in a later increment.

All data on this page is synthetic. The historical system this reconstructs (documented in dashboard-audit.md) had five specific, unresolved data anomalies: a mismatch between total leads and the sum of status counts, an unreconciled conversion percentage, a negative channel count, person names leaking into a source field, and an unconfirmed channel-grouping rule. Those anomalies are described in the project's evidence documents, not reproduced here — the numbers on this page are deliberately clean and internally consistent, per DASHBOARD_BUILD_CONTRACT.md. The "Canal" grouping shown here follows an explicit synthetic mapping table (visible in input/canal_mapping.csv), not the historical, unconfirmed production rule.
