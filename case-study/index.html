Pipeline y Dashboard de Datos de Marketing — Caso de Estudio

Qué es este caso

Pipeline de datos de marketing, Universidad de Chile, Educación Ejecutiva — consolidando información de más de cinco fuentes operacionales heterogéneas en una única base de contactos confiable, a una escala superior a 250.000 contactos activos y 400.000 registros históricos. Este caso de estudio reconstruye ese trabajo para demostración pública; no es una exportación del sistema original.

El problema

Los datos de contactos y matrículas vivían dispersos en fuentes operacionales heterogéneas y desconectadas, exigiendo trabajo manual repetido antes de que fueran utilizables para segmentación, campañas o reportería.

La reconstrucción

La reconstrucción se divide en dos demostraciones enlazadas y autocontenidas, cada una abordando una etapa de la misma historia y cada una declarando sus propios datos sintéticos: una Vista Pipeline, que cubre la consolidación de datos, y una Vista Dashboard, que cubre la visibilidad operacional del ciclo de vida del prospecto.

Qué mirar primero

Abre la Vista Pipeline para ver fuentes heterogéneas limpiadas, normalizadas y consolidadas en una base de contactos. Abre la Vista Dashboard para ver cómo esa base consolidada sostiene la visibilidad de dónde están los prospectos, desde la adquisición hasta la matrícula.

Qué no es esto

Este no es el sistema organizacional original y no se exporta ni se muestra ningún dato de producción: ambas demostraciones enlazadas funcionan íntegramente con datos sintéticos. Nada aquí afirma un resultado de negocio medido específico; la cadencia confirmada de reportería del flujo original era horaria, y no se afirma que ningún modelo experimental haya alcanzado uso permanente en producción.
