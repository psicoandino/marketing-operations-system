# Recovered Artifacts

This directory stores original technical artifacts recovered from the operator's personal archive.

Recovered artifacts supersede operator testimony whenever they provide direct evidence of the implemented work.

## Contents

- `notebook_resp.PRIVATE.Rmd` — original recovered R notebook. Contains credentials, internal hosts and personal paths. **Excluded from Git** by this directory's `.gitignore`; never commit it.
- `notebook_resp.SANITIZED.md` — tracked technical evidence derived from the private notebook. Preserves structure and transformation logic with all sensitive values replaced by explicit placeholders.
